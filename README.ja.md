# typed-ipv4-echo

LinuxのTUNデバイスを使用してTCP、UDP、ICMPプロトコルを実装した型安全なユーザー空間IPv4エコーサーバーです。

## 概要

このプロジェクトは、TCPハンドシェイク、UDPデータグラム、ICMPエコー要求を処理するユーザー空間エコーサーバーを実装することで、Rustにおける低レイヤーネットワーキングの学習のために作成したものです。ソケットにバインドするのではなく、仮想TUNネットワークインターフェースを作成し、生のIPv4パケットを直接処理することで、型安全性、パフォーマンス、保守性を保ちつつプロトコル実装の詳細を理解することを目指しました。

## 機能

- **複数プロトコル対応**：ICMPエコー要求・応答、TCPスリーウェイハンドシェイクとデータエコー、UDPエコーを処理
- **TUNデバイス統合**：`libc`とLinux TUN仮想ネットワークインターフェースを使用した低レイヤーパケット入出力
- **型安全なパケット解析**：Rustの強力な型システムとゼロコスト抽象化を活用し、生のバイト列を安全にプロトコル構造として解釈
- **グレースフルシャットダウン**：SIGINTを処理し、正常に終了
- **包括的なテスト**：エッジケースをカバーする全パケット処理ロジックのユニットテスト
- **厳格なリント**：`unwrap`と`expect`を完全に禁止し、限定的な`unsafe`の使用を分離
- **継続的インテグレーション**：CIでテスト、リント、フォーマットチェック、スペルチェックを実行し、mainへのマージには合格を必須とする

## アーキテクチャ

本サーバーの設計では、`ProtocolHandler`トレイト（インターフェース）を使用して、プロトコルに依存しないIPv4処理とプロトコル固有のロジックを分離しています。同時に、明瞭性や保守性を実際に向上させる場合にのみヒープを使用するよう配慮しています。

```
┌────────────────────────────────────┐
        TUNデバイス・メインループ
          シャットダウンシグナル
└────────────────┬───────────────────┘
                 │
                 ▼
┌────────────────────────────────────┐
             IPv4ヘッダー
            解析・書き込み
└────────────────┬───────────────────┘
                 │
                 ▼
┌───────────────────────────────────┐
       ProtocolHandlerトレイト
        （Boxによる実行時多態性）
└────┬───────────┬───────────┬──────┘
     │           │           │
     ▼           ▼           ▼
┌─────────┐ ┌─────────┐ ┌─────────┐
│  ICMP   │ │   TCP   │ │   UDP   │
│ handler │ │ handler │ │ handler │
└─────────┘ └─────────┘ └─────────┘
```

各具体的なプロトコルハンドラは`ProtocolHandler`トレイトを実装し、以下を行います：

- 生のバイト列からプロトコル固有のヘッダーとペイロードを解析
- 適切な応答パケットを書き込む

この設計では、vtableルックアップと1パケットペアあたり1つの`Box`（参照カウントなしのヒープ割り当てスマートポインタ）のコストがかかりますが、依存性注入によるテストの容易性とIPv4とTCP/UDP/ICMPの関心の明確な分離を実現しています。

エラーメッセージは実行時データを読みやすく安全に含めるために`String`ヒープ割り当てを使用していますが、パケットデータの本体はすべてスタック上の2つの固定サイズ配列で管理されています。

## サーバーの実行

### 前提条件

- Linux（TUNデバイスサポートが必要）
- Rustツールチェイン（[こちらからインストール](https://rust-lang.org/tools/install/)）
- `sudo`権限（ネットワークインターフェース作成に必要）
- 【任意】[just](https://github.com/casey/just)コマンドランナー

### サーバーのビルドと実行

サーバーバイナリはTUNデバイスの作成と設定のために`sudo`権限で実行する必要があります。`just`コマンドはサーバーをビルドして実行し、`sudo`の確認を求めます。

```bash
just
```

または手動で：

```bash
cargo build
sudo ./target/debug/typed-ipv4-echo
```

サーバーは`10.0.0.1/24`にTUNデバイスを作成し、SIGINT（Ctrl+C）を受信するまで、パケットを待ち受けて応答しながら処理したデータをログ出力します。

## クライアントからの接続

サーバーを実行した状態で、別のターミナルから各プロトコルで接続してみることができます。TCPまたはUDPで接続する場合は、メッセージを入力してEnterキーを押すと送り返されます。

```bash
just tcp
just udp
just icmp
```

または手動で：

```bash
telnet 10.0.0.2 8080  # TCP
nc -u 10.0.0.2 8080   # UDP
ping 10.0.0.2         # ICMP
```

## テスト

テストスイートを実行：

```bash
cargo test
```

本プロジェクトには以下の包括的なユニットテストが含まれています。

- インターネットチェックサム計算
- IPv4ヘッダー解析と生成
- ICMPエコー要求・応答処理
- TCPハンドシェイクとデータエコーロジック
- UDPデータグラム解析とエコー応答
- 不正なパケット、空のペイロード、境界値などのエッジケース
